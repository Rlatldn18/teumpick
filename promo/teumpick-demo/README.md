# 틈픽 30초 제품 콘셉트 시연 영상

결과물: `teumpick-demo-30s.mp4` (1080×1920, 24fps, 30초, H.264/AAC)

| 시간 | 장면 | 전달할 메시지 |
| --- | --- | --- |
| 0–3.5초 | 환승역의 이용자와 틈픽 보관함 | 환승길에 식사할 시간이 부족하다 |
| 3.5–8초 | 현재 앱 디자인을 따른 가게 탐색 화면 | 역과 메뉴를 고른다 |
| 8–12초 | 현재 앱 디자인을 따른 장바구니 화면 | 이동 전에 미리 주문한다 |
| 12–16초 | 가게가 음식을 준비하는 장면 | 가게가 주문을 준비한다 |
| 16–21초 | 앱 주문 정보와 보관함 | 역에서 보관함 번호와 수령 코드를 확인한다 |
| 21–24초 | 이용자가 키패드에 코드 입력 | 향후 하드웨어 동작 방식 시연 |
| 24–27초 | 같은 보관함의 03번 문 열림 | 기다림 없이 픽업한다 |
| 27–30초 | 틈픽 슬로건과 개발 예정 안내 | 브랜드와 제품 가치 마무리 |

보관함은 `assets/locker.png` **한 장**을 기준으로 전 장면에 합성했습니다. 문 열림 컷은 같은 이미지를 복제한 뒤 03번 문만 열린 모습으로 그렸습니다. 나머지 격자·색상·크기·간판·번호는 고정되어 있습니다. 인물과 배경은 AI로 만든 장면이며 현재 실물 보관함은 존재하지 않습니다.

앱을 다른 제품처럼 보이게 하지 않기 위해 `app/globals.css`의 초록색 `#087f54`, 배경색, 실제 한글 화면 문구와 구매자 흐름을 참고해 영상용 전화 화면을 결정적으로 그렸습니다. 영상용 UI는 코드 기반 재현 화면이며, 원본 앱의 픽셀 단위 녹화본은 아닙니다. 현재 앱의 주문은 시범 주문이며 실제 결제되지 않습니다. 따라서 영상의 보관함 개방은 `보관함 콘셉트`로 표시했고 마지막에도 개발 예정 사실을 밝혔습니다.

다시 만들기:

1. `python render_demo.py`로 장면 이미지 8장과 콘택트 시트를 생성합니다.
2. Windows 한국어 음성 `Microsoft Heami Desktop`이 있다면 `powershell -File narration.ps1`로 음성을 생성합니다.
3. `python build_video.py`로 MP4를 합칩니다. 이 스크립트는 `.deps` 안의 FFmpeg가 필요합니다.

`subtitles.srt`에 내레이션 자막을 별도로 담았습니다. `contact-sheet.png`에서 전체 장면을 한눈에 볼 수 있습니다.
